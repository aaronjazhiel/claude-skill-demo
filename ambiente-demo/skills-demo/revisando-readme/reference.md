# Qué debe contener cada sección

## Requisitos
Versiones mínimas de runtime, dependencias de sistema, variables de entorno
obligatorias. Con números de versión, no "reciente".

## Instalación
Comandos exactos, copiables, en orden.

## Uso
Al menos un ejemplo completo que funcione al copiarlo.

## Configuración
Tabla de variables: nombre, para qué sirve, valor por defecto, si es obligatoria.

## Desarrollo
Cómo levantar el entorno local, cómo correr las pruebas.

## Licencia
Nombre de la licencia y enlace al archivo.
